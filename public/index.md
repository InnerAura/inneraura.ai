# HyperWeave — Diagrams, Tables & Charts for AI Agents

HyperWeave is an open-source visual artifact compiler for AI agents, producing deterministic diagrams, tables, and charts that humans can see and agents can read back.

## Agents move faster than people can see.

Better models mean more autonomy, bigger changes, and more parallel work, which leaves less of it that anyone can actually review. More text doesn't fix that. Clearer views do.

## Don't redraw it. Continue it.

In most agent conversations, the diagram from turn one and the diagram from turn three are related only by the model's memory. Nothing persists between them.

HyperWeave puts a real object in the middle. The person looks at it. The agent reads it, edits it, and compares versions. Your tests can check it. Everyone works on the same artifact.

The thing your agent drew is the thing your agent can read back.

## One artifact. Every surface.

The same source renders wherever the work happens:

- Browser: live, animated SVG
- Docs and READMEs: static SVG, embedded like any image
- Terminal: ANSI
- Anywhere else: PNG / WebP

## Same meaning. Any shape.

Pipelines, DAGs, state machines, sequence diagrams, trees, and comparison tables. Give HyperWeave the structure and it handles the layout. When the content or the space changes, the layout adapts. A dense graph goes vertical; a workflow becomes lanes. The meaning stays the same.

## HyperWeave (open source)

Structured input in. Diagrams, tables, and charts out. Compose through MCP, CLI, HTTP, or an Agent Skill. Then extract, query, transform, diff, or verify the result. Identical input produces identical output every time.
